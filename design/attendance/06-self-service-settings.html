Self-service settings

A new block in the organization's attendance card, between the ceilings and location. One switch turns employee self-service on; while it is on, the admin picks a number of days back or no limit. The line under the control says in plain words what employees can do with the setting as it stands, with the actual dates for today. Group admins cannot open this page, so they read the setting on Team attendance instead.

Every state of the control

Off is where a new organization starts. On with 0 days is where an organization that already used attendance lands after the change, because it is the rule they have today. The number field only shows while "Days back" is picked, and it takes 0 to 366.
