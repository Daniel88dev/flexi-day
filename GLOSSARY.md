# Context: flexi-day

The web app. The backend's glossary in `flexi-day-be/GLOSSARY.md` owns the domain terms (vacation,
group, organization, Assistant, AI connection); this file adds only the terms the web app coins.
Use the backend's words for everything else.

## Glossary

| Term               | Meaning                                                                                                                                                                                                                     |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Help article**   | One page of user help on one topic, written in English with a Czech sibling and public at its own address. The Assistant and AI connections answer how-to questions from them and link to them. Avoid: doc, FAQ, help page. |
| **Knowledge base** | Every help article plus a short product overview, in both languages, published as one bundle the Assistant and AI connections search. Avoid: docs, help center.                                                             |
